# Getting Started with Drips Wave

This guide walks you through everything you need to do before you can claim your first Drips Wave issue.

## What Is Drips Wave?

Drips Wave is a recurring bounty cycle where developers resolve issues in open-source projects and earn rewards. Each Wave runs for a set period (typically one week per month), contributors apply for scoped issues, and rewards are distributed based on points earned.

Think of it as a structured sprint that gives you:
- **Clear tasks** with defined scope and acceptance criteria
- **Fair compensation** based on complexity and impact
- **A verifiable portfolio** of merged contributions

## Prerequisites

Before you can participate, you need three things:

| Requirement | Why You Need It | Where to Get It |
|-------------|-----------------|-----------------|
| **GitHub Account** | To apply for issues and submit PRs | [github.com](https://github.com) |
| **Drips Wave Account** | To browse Waves and earn points | [Drips Wave App](https://drips.network) |
| **Stellar Wallet + KYC** | To receive USDC rewards | See wallet setup below |

## Step 1: Create Your Drips Wave Account

1. Go to the **Drips Wave app** and click **Sign In**.
2. Authenticate with your **GitHub account**.
3. Complete your profile — add a bio and link to your GitHub so maintainers can learn about you.

## Step 2: Set Up Your Stellar Wallet

Drips Wave pays rewards in **USDC on the Stellar network**. You'll need a Stellar wallet that supports USDC.

### Recommended Wallets

- **Freighter** — browser extension, beginner-friendly
- **xBull** — feature-rich, good for advanced users
- **Lobstr** — mobile-friendly

### Wallet Setup Checklist

- [ ] Create a Stellar wallet
- [ ] Fund it with a small amount of XLM (for account activation)
- [ ] Add a **USDC trustline**
- [ ] Save your **wallet address** (starts with `G...`)
- [ ] Save your **secret key** somewhere safe (never share this)

**Important:** Without a USDC trustline, you cannot receive rewards. Most wallets have a "Add Asset" or "Trustline" option — search for USDC.

## Step 3: Complete KYC Verification

Drips Wave requires **identity verification (KYC)** before you can apply for issues. This is a regulatory requirement for reward distribution.

1. In the Drips Wave app, navigate to **Settings → Identity and Payments**.
2. Follow the verification steps (typically a government ID and a selfie).
3. Wait for approval — most verifications complete within minutes, but some take longer.

**Why upfront?** Starting in Wave 5, KYC is required before applying to any issue. This ensures payouts can move quickly once a Wave ends.

### Troubleshooting KYC

- **Verification stuck?** Check your email for updates from the verification provider.
- **Rejected?** Contact Drips support via the app's chat widget or Discord.
- **Already verified?** You're good — no need to redo it.

## Step 4: Find an Active Wave

1. In the Drips Wave app, go to the **Explore** page.
2. Find an active Wave Program (e.g., "Stellar Wave").
3. Click **Issues** to see available tasks.

Each Wave card shows:
- **Reward Budget** — the total pot for that Wave
- **Time Window** — when the sprint ends
- **Issue Count** — how many tasks are available

## Step 5: Prepare Your GitHub Profile

Maintainers review your GitHub activity when you apply for issues. A strong profile helps your application stand out.

### What Maintainers See

- **Total Merged PRs** — your contribution history
- **PR Merge Rate** — percentage of your PRs that get merged
- **OSS Activity Score** — overall open-source engagement

### Quick Wins

- Pin 2–3 of your best repositories to your profile
- Add a README to your personal profile repo
- Make sure your email is verified
- Consider linking your Drips Wave profile to your GitHub bio

## You're Ready

With your account, wallet, and KYC complete, you can now browse and apply for issues. See the [claiming issues guide](claiming-issues.md) for next steps.

## Common Setup Mistakes

| Mistake | Consequence | Fix |
|---------|-------------|-----|
| No USDC trustline | Cannot receive rewards | Add trustline in wallet settings |
| Skipping KYC | Cannot apply for issues | Complete verification in Settings |
| No XLM in wallet | Wallet not activated | Send a small amount of XLM |
| Unverified GitHub email | Application may be ignored | Verify in GitHub settings |
