# Finding Good First Issues

A "good first issue" is a task specifically chosen because it's approachable for newcomers — clear scope, limited dependencies, and helpful context. This guide helps you find and evaluate them.

## Where to Find Issues

### Drips Wave App

The primary place to find Wave issues:

1. Go to the **Explore** page.
2. Select an active Wave Program.
3. Click **Issues** to see the full list.
4. Filter by:
   - **Unassigned** — issues no one has claimed yet
   - **No Applications** — issues without competing applicants
   - **Complexity** — Trivial, Medium, or High
