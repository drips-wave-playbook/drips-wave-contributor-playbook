# Earning Drips Points

Every issue in a Drips Wave has a **point value** based on its complexity. This guide explains how points work, how they convert to rewards, and how to maximize your earnings.

## The Point System

Points are **shares** in the Wave reward pool — not a fixed dollar amount. The more points you earn relative to other contributors, the larger your payout.

### Complexity Levels

| Complexity | Base Points | Bonus | Total | Best For |
|------------|-------------|-------|-------|----------|
| **Trivial** | 100 | +0 | **100** | Typos, broken links, minor copy changes |
| **Medium** | 100 | +50 | **150** | New sections, examples, small features |
| **High** | 100 | +100 | **200** | Comprehensive guides, refactors, translations |

Maintainers assign complexity when adding issues to a Wave. If you think an issue was misclassified, discuss it with the maintainer **before** completing it.
