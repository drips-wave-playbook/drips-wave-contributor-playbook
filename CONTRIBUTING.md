## Before You Start

This is a **documentation repository** — you don't need to install any software to contribute. All work happens in Markdown files and templates.

Before claiming your first issue:

1. **Complete KYC** on the Drips Wave app if you plan to earn rewards.
2. **Read the issue description carefully** — make sure you understand the acceptance criteria.
3. **Check the issue's complexity** — Trivial, Medium, and High issues have different point values.

## How to Claim an Issue

1. **Browse open issues** on our [Issues page](https://github.com/YOUR-ORG/drips-wave-contributor-playbook/issues).
2. **Find one labelled `good first issue`** if you're new, or any issue that matches your skills.
3. **Comment on the issue** with a brief message stating you'd like to work on it.
4. **Wait for assignment** — a maintainer will assign the issue to you. Do not start work until assigned.
5. **Ask questions** in the issue comments if anything is unclear.

If you're claiming through the Drips Wave app, use the **Apply** button and write a concise message.
