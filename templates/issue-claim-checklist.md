# Issue Claim Checklist

Use this checklist before applying for any Drips Wave issue.

## Issue Evaluation

- [ ] I have read the **full issue description**
- [ ] I understand the **acceptance criteria**
- [ ] The scope is **clear and specific**
- [ ] Complexity matches my skill level
- [ ] I can complete this within the Wave timeframe
- [ ] The issue is **not already assigned**

## Competition Check

- [ ] Applicant count is reasonable (0–3 is ideal)
- [ ] No other PR is already open for this issue
- [ ] The repo has recent maintainer activity

## Application Preparation

- [ ] I have a **specific plan** for resolving this issue
- [ ] I can articulate **why I'm a good fit**
- [ ] I have relevant experience or examples to mention
- [ ] My application message is **concise** (3–5 sentences max)

## Platform Limits

- [ ] I have fewer than **15 pending applications**
- [ ] I have fewer than **4 assignments** in this organization

## Before Submitting

- [ ] I will **wait for assignment** before starting work
- [ ] I understand the **Wave deadline**
- [ ] I know how to **contact the maintainer** if blocked

## Post-Application

- [ ] I've noted the issue number for tracking
- [ ] I'll check my Drips dashboard for assignment updates
- [ ] I won't start work until officially assigned
