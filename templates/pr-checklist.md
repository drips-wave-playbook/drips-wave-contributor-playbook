# Pull Request Checklist

Use this checklist before submitting any Drips Wave PR.

## Pre-Submission

- [ ] I am **officially assigned** to the issue
- [ ] I have read the **acceptance criteria** again
- [ ] My changes match the issue scope
- [ ] No unrelated files or changes are included

## Content Quality

- [ ] All links work (internal and external)
- [ ] Markdown renders correctly
- [ ] No spelling or grammar errors
- [ ] Style follows existing conventions
- [ ] Code blocks have language identifiers (where applicable)
- [ ] Tables are properly formatted

## Git Hygiene

- [ ] Branch name is descriptive
- [ ] Commit messages are clear and conventional
- [ ] No merge conflicts with base branch
- [ ] I'm not force-pushing during an active review

## PR Description

- [ ] Used the PR template
- [ ] **Issue linked with `Closes #<number>`**
- [ ] Description explains what and why
- [ ] Checklist is complete

## Post-Submission

- [ ] I will respond to review feedback within 24 hours
- [ ] I will verify the issue closes after merge
- [ ] I will check my points dashboard after merge
